# INSCIENCE — головна сторінка (прототип)

Статична версія головної сторінки сайту ГО «INSCIENCE», експортована з дизайн-прототипу.

- `index.html` — сторінка (HTML, CSS і JS в одному файлі)
- `assets/` — шрифт Recht, логотипи, брендові фігури, фото й фавіконки

Усі посилання навмисно порожні (`#`). Сторінка працює без збірки: достатньо відкрити `index.html` або увімкнути GitHub Pages для гілки `main`.

Розроблено в Opentech | SoftServe.
